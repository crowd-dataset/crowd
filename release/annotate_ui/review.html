Check the boxes

The boxes are the detector's (confidence ≥ 0.7). Each counts as correct unless you change it. Click a box, then press X if there is no such object there (false positive), or the key of the class it really is (1-8) if the class is wrong. Then look for any person, bicycle, car, motorcycle, bus, truck, traffic light or stop sign that has no box (missed): press its class key first (nothing selected), then drag a box around it. Look at every box and at the whole frame before you press Enter.
