Track ()

Only the red box is the track. Watch it and decide whether it stays on one and the same object from start to end, or at some moment jumps to another one. A long track is shown in up to three pieces (its start, middle and end), played in a loop; when it jumps to the next piece the box disappears for a moment.

Keys: 1 same object, 2 jumps to another object, 3 not a road user, 4 cannot tell, Enter saves.
